# paperclip_plugin_config (Resource)

Manages company-scoped configuration for a Paperclip plugin. Destroy relinquishes management without clearing remote configuration; the API has no config deletion route.

## Example Usage

```terraform
resource "paperclip_plugin_config" "linear" {
  company_id = paperclip_company.acme.id
  plugin_id  = paperclip_plugin.linear.id
  config = jsonencode({
    apiKey = {
      type     = "secret_ref"
      secretId = paperclip_secret.api_token.id
    }
  })
}
```

## Schema

### Required

- `company_id` (String) Paperclip company ID owning this plugin configuration.
- `config` (String) Plugin configuration JSON object conforming to the plugin's instanceConfigSchema.
- `plugin_id` (String) Plugin UUID or plugin key being configured.

### Read-Only

- `id` (String) Composite identifier in company_id/plugin_id format.
- `last_error` (String) Most recent configuration validation error recorded by Paperclip.
