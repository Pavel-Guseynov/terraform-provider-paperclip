# paperclip_skill_policy (Resource)

Manages the company skill policy with revision check and conflict detection.

## Example Usage

```terraform
resource "paperclip_skill_policy" "company_policy" {
  company_id     = paperclip_company.acme.id
  default_effect = "allow"
  rules = jsonencode([
    {
      id       = "allow-skill-updates"
      priority = 100
      effect   = "allow"
      subject  = { type = "all_agents" }
      actions  = ["skills.edit", "skills.update"]
    }
  ])
}
```
