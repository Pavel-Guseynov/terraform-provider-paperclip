# paperclip_agent_instruction_bundle (Resource)

Manages an agent's instruction bundle as complete desired state (bundle mode, entry file, multi-file desired state, and legacy prompt template clearing).

## Example Usage

```terraform
resource "paperclip_agent_instruction_bundle" "engineer_bundle" {
  agent_id   = paperclip_agent.engineer.id
  mode       = "managed"
  entry_file = "AGENTS.md"
  files = {
    "AGENTS.md" = "# Agent Instructions\n"
  }
}
```

## Schema

### Required

- `agent_id` (String) The Paperclip agent ID.

### Optional

- `clear_legacy_prompt_template` (Boolean) Whether to explicitly clear legacy promptTemplate and bootstrapPromptTemplate adapter configurations.
- `entry_file` (String) Relative entry file path within the bundle (defaults to 'AGENTS.md').
- `files` (Map of String) Complete desired set of native editable, non-virtual files (relative path -> file content). Undeclared editable files are removed on apply; virtual and producer-owned files remain intact.
- `mode` (String) Bundle mode ('managed' or 'external'). External mode requires instance-admin authorization and an absolute root_path.
- `root_path` (String) Filesystem root path of the instruction bundle. Required and must be an absolute path when mode is 'external'; computed by the server when 'managed'.

### Read-Only

- `file_inventory` (List of Objects, see [below for nested schema](#nestedatt--file-inventory)) Read-only inventory of all files present in the bundle (including virtual, deprecated, or producer-owned files) as reported by the server.
- `id` (String) Unique identifier for the instruction bundle (agent ID).
