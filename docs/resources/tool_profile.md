# paperclip_tool_profile (Resource)

Single aggregate writer of one native tool profile and its complete entries set. Bindings have separate resources. Finish-route profiles cannot be claimed.

## Example Usage

```terraform
resource "paperclip_tool_profile" "qa" {
  company_id     = paperclip_company.acme.id
  profile_key    = "qa-read"
  name           = "QA scoped access"
  status         = "active"
  default_action = "deny"
  metadata       = jsonencode({ owner = "platform" })
  entries = jsonencode([
    { selectorType = "tool_name", toolName = "read_issue", effect = "include" }
  ])
}
```

## Schema

### Required

- `name` (String)
- `profile_key` (String) Company-unique profile key. The app: namespace is reserved for app_permission.

### Optional

- `default_action` (String)
- `description` (String) Native description. A non-null value cannot be cleared to null; empty string is supported.
- `entries` (String) Complete JSON array of up to 250 native entries (camelCase fields). Replaced as one set; omitted entries are removed only from this profile. Catalog schemas and producer annotations are never written.
- `force_destroy` (Boolean) Explicitly permit deletion of the company default profile.
- `metadata` (String) Native metadata object. Use {} to clear; non-null metadata cannot become null. source=app_gallery_finish is reserved.
- `reassign_to_profile_id` (String) Explicit native deletion target for existing bindings; must be a different active profile in this company, outside app_permission ownership.
- `status` (String)
