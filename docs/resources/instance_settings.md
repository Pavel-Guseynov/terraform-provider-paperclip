# paperclip_instance_settings (Resource)

Owns only declared instance settings. Deployment-owned keys fail before mutation. Requires instance admin access. Destroy relinquishes ownership and retains settings. Import instance to adopt writable values; configure the imported keys. Native section PATCHes are independent, so partial failures retain observed state for reconciliation.

## Example Usage

```terraform
resource "paperclip_instance_settings" "instance" {
  default_environment_id = var.default_environment_id
  general = jsonencode({
    censorUsernameInLogs = true
    keyboardShortcuts = true
    feedbackDataSharingPreference = "prompt"
    backupRetention = { dailyDays = 7, weeklyWeeks = 4, monthlyMonths = 1 }
    executionMode = "any"
  })
  experimental = jsonencode({ enableEnvironments = true })
}
```
