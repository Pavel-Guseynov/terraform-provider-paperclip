# paperclip_mcp_gateway (Resource)

Manages a named MCP gateway through the existing tools:admin board API. Import as company_id/gateway_id. Destroy archives without setting archivedAt or deleting bindings/tokens. Profile updates retain old native bindings; coordinate their ownership separately.

## Example Usage

```terraform
resource "paperclip_mcp_gateway" "automation" {
  company_id = paperclip_company.acme.id
  name = "Automation gateway"
  slug = "automation"
  profile_id = paperclip_tool_profile.automation.id
  default_profile_mode = "gateway_only"
  context_scope_type = "none"
  on_demand_tools_config = jsonencode({ enabled = true })
}
```
