# paperclip_connection_grants (Resource)

Single aggregate owner of a connection's default organization installation grant, its member audience, and declared personal-grant delegations. Rotation revokes superseded organization grants. Personal credentials require native consent; this resource never mints or resolves credentials. Separate states must coordinate ownership externally because the native API has no owner/CAS field.

## Example Usage

```terraform
resource "paperclip_connection_grants" "gitea_grants" {
  company_id    = paperclip_company.acme.id
  connection_id = paperclip_connection.gitea_conn.id
  credential_secret_refs = {
    "credentials.api_key" = {
      secret_id = paperclip_secret.api_token.id
      version   = "latest"
    }
  }
}
```

### Optional

- `credential_secret_refs` (Map of Objects, see [below for nested schema](#nestedatt--credential-secret-refs)) Protected company secret references keyed by native configPath. Versions use latest or a positive integer string. Contains reference identities only, never credential values.

- `member_user_ids` (Set of String) Default organization grant audience. An empty set means all company members in the native API.

### Read-Only

- `id` (String)
- `owner_id` (String) Provider ownership identity for this aggregate.
- `ready` (Boolean) Whether the default grant is active and superseded organization grants are revoked.
