# paperclip_goal (Resource)

Manages a Paperclip goal entity and its hierarchy under a company.

## Example Usage

```terraform
resource "paperclip_goal" "q4_delivery" {
  company_id     = paperclip_company.acme.id
  title          = "Deliver OpenTofu Provider Export"
  description    = "Publish standard OpenTofu Registry provider repository"
  level          = "company"
  status         = "active"
  owner_agent_id = paperclip_agent.engineer.id
  retirement     = "fail"
}
```

## Schema

### Required

- `company_id` (String) The Paperclip company ID.
- `title` (String) Goal title.

### Optional

- `cancel_on_destroy` (Boolean) Whether to cancel the goal (status = cancelled) when destroyed if still referenced (defaults to false).
- `description` (String) Optional goal description. Explicitly clearable to null.
- `level` (String) Goal level: company, team, agent, or task (defaults to task).
- `owner_agent_id` (String) Optional owner agent identifier.
- `parent_id` (String) Optional parent goal identifier for hierarchy relationships.
- `retirement` (String) Retirement behavior when destroying a referenced goal: 'fail' (default) or 'cancel'.
- `status` (String) Goal status: planned, active, achieved, or cancelled (defaults to planned).

### Read-Only

- `id` (String) Unique identifier for the goal.
