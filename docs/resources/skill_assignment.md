# paperclip_skill_assignment (Resource)

Manages desired skill assignments and version pins for a Paperclip agent as the sole writer of adapterConfig.paperclipSkillSync.

## Example Usage

```terraform
resource "paperclip_skill_assignment" "engineer_skills" {
  agent_id = paperclip_agent.engineer.id
  skills = [
    {
      key        = paperclip_skill.task_lifecycle.key
      version_id = paperclip_skill.task_lifecycle.current_version_id
    }
  ]
}
```
