# paperclip_routine_trigger (Resource)

Manages native routine triggers. New webhooks adopt pending generation 1 from the ephemeral producer before write-only consumption; paperclip_routine_webhook_delivery acknowledges delivery afterwards. Rotation is rejected. Imported webhooks support metadata and native deletion. Kind and routine ownership cannot change.

## Example Usage

```terraform
resource "paperclip_routine_trigger" "daily" {
  routine_id      = paperclip_routine.daily.id
  kind            = "schedule"
  cron_expression = "0 9 * * *"
  timezone        = "UTC"
}
```

### Required

- `routine_id` (String) Owning routine identity; immutable.

### Optional

- `cron_expression` (String) Required only for schedule triggers. Native cron syntax; cannot be cleared on schedules.
- `enabled` (Boolean) Whether the trigger is enabled; default true.
- `label` (String) Nullable label, at most 120 characters; omitted configuration clears it.
- `replay_window_sec` (Number) Webhook replay window, 30–86400 seconds; nullable. Match the initial ephemeral producer settings.
- `signing_mode` (String) Webhook signing mode: bearer, hmac_sha256, github_hmac, or none; nullable. Match the initial ephemeral producer settings.
- `timezone` (String) Required only for schedule triggers. Native IANA timezone; use UTC explicitly. Cannot be cleared on schedules.
- `webhook_delivery_name` (String) Stable generation-1 delivery identity matching the ephemeral producer. Required for webhook creation; omit for metadata-only imports. Immutable.
- `webhook_generation` (Number) Credential generation; default 1. Rotation is unsupported and larger generations are rejected before mutation.

### Read-Only

- `id` (String) Native trigger identity.
