# paperclip_local_environment (Resource)

Owns service PATH inheritance on the existing Paperclip Local environment. Removing this resource releases management without deleting the environment or restoring an obsolete override.

## Example Usage

```terraform
resource "paperclip_local_environment" "host" {
  company_id           = paperclip_company.acme.id
  inherit_service_path = true
}
```

## Schema

### Required

- `company_id` (String) Company context for native environment binding reconciliation.
- `inherit_service_path` (Boolean) Must be true. Read reports false when a persisted PATH binding overrides the Nix service PATH, so refresh plans its removal.

### Read-Only

- `id` (String) Existing Local environment ID; creation or replacement of the environment is not supported.
