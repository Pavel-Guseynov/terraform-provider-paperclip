# paperclip_tool_profile_binding (Resource)

Owns one scoped profile binding. Import as company_id/profile_id/binding_id using the native profile inventory. Native bind is insert-only: attribute changes fail without unbinding or replacing the existing identity. Explicitly retire the resource before creating a different binding. Duplicate bindings conflict; finish-route profiles are excluded.

## Example Usage

```terraform
resource "paperclip_tool_profile_binding" "qa" {
  company_id  = paperclip_company.acme.id
  profile_id  = paperclip_tool_profile.qa.id
  target_type = "agent"
  target_id   = paperclip_agent.engineer.id
  priority    = 100
}
```
