# paperclip_budget_policy (Resource)

Manages a Paperclip budget policy across company, agent, or project scopes.

## Example Usage

```terraform
resource "paperclip_budget_policy" "monthly_cap" {
  company_id        = paperclip_company.acme.id
  scope_type        = "company"
  scope_id          = paperclip_company.acme.id
  metric            = "billed_cents"
  window_kind       = "calendar_month_utc"
  amount            = 500000
  warn_percent      = 80
  hard_stop_enabled = true
  notify_enabled    = true
}
```

### Required

- `amount` (Number) Budget limit amount in cents. Must be non-negative.
- `company_id` (String) The Paperclip company ID.
- `scope_id` (String) Target identifier of the company, agent, or project.
- `scope_type` (String) Scope type for the policy: company, agent, or project.

- `hard_stop_enabled` (Boolean) Optional alias for hard_stop.
- `is_active` (Boolean) Optional alias for active.

- `notify` (Boolean) Whether notification is enabled (defaults to true).

- `window_kind` (String) Window kind for the policy: calendar_month_utc or lifetime (defaults to calendar_month_utc).
