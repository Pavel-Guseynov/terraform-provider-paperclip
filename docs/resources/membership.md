# paperclip_membership (Resource)

Adopts and manages an existing human company membership (role, status, and archive with reassignment).

## Example Usage

```terraform
resource "paperclip_membership" "operator" {
  company_id = paperclip_company.acme.id
  user_id    = data.paperclip_user.operator.id
  role       = "operator"
  status     = "active"
}
```

## Schema

### Required

- `company_id` (String) Company identifier owning the membership.
- `user_id` (String) User identifier (principalId) of the human member.

### Optional

- `archive_on_destroy` (Boolean) Whether to archive the membership on destroy via POST /archive (defaults to true).
- `reassignment_agent_id` (String) Optional target agent identifier for reassignment when archiving on destroy.
- `reassignment_user_id` (String) Optional target user identifier for reassignment when archiving on destroy.
- `role` (String) Human membership role: owner, admin, operator, or viewer (defaults to operator).
- `status` (String) Membership status: active, suspended, or pending (defaults to active).

### Read-Only

- `id` (String) Unique identifier for the membership.
