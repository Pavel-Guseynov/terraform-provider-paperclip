# paperclip_environment (Resource)

Manages an instance-scoped execution environment through the native API. Import Local; never create or replace its singleton. Same-driver config keys cannot be removed: such plans fail before writes. Native delete blocks are errors. Use protected secret references, never credentials in config. Transfer Local ownership by forgetting the old PATH binding without destruction and importing this resource; retain the old binding until the consumer cutover is ready.

## Example Usage

```terraform
resource "paperclip_environment" "remote" {
  company_id = paperclip_company.acme.id
  name       = "Remote SSH"
  driver     = "ssh"
  config = jsonencode({
    host                = "ssh.example.com"
    username            = "agent"
    remoteWorkspacePath = "/workspace"
    privateKeySecretRef = { type = "secret_ref", secretId = var.ssh_key_secret_id, version = "latest" }
  })
  env = { EDITOR = { type = "plain", value = "vi" } }
}
```

## Schema

### Required

- `company_id` (String) Secret-resolution context only; environments have no company ownership. Import as company_id/environment_id.
- `config` (String, Sensitive) Native driver config JSON object (camelCase). SSH: host, username, absolute remoteWorkspacePath, optional port (22), strictHostKeyChecking (true), knownHosts and privateKeySecretRef; plaintext privateKey is rejected. Sandbox: installed provider key, optional reuseLease (false), timeoutMs, streamRunLogs, runnerLifecycleMode, runnerIdleTimeoutMs, archiveOnRelease and provider-specific fields. The fake provider cannot be saved. Plugin: pluginKey, driverKey, driverConfig. Local: native config object. Include normalized plugin defaults; the server owns plugin-specific validation. Removing an existing top-level key on the same driver is unsupported.
- `driver` (String) local, ssh, sandbox or plugin. Local identity cannot change driver.
- `name` (String) Native environment name.

### Optional

- `description` (String) Description; omission clears it to null. Empty string is preserved.
- `env` (Map of Objects, see [below for nested schema](#nestedatt--env)) Complete envVars map using shared plain, secret_ref and user_secret_ref bindings. Omission clears bindings; omit PATH to inherit the service PATH. Only one resource may own Local envVars.
- `metadata` (String) Metadata JSON object; omission clears it to null. Platform-owned fields remain subject to native restrictions.
- `status` (String) active (default) or archived.

### Read-Only

- `id` (String) Native environment ID, preserved across updates and imports.
