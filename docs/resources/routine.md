# paperclip_routine (Resource)

Manages a native Paperclip routine. Destroy archives with a revision guard. Active routines require an assignee; native template normalization is checked before mutation.

## Example Usage

```terraform
resource "paperclip_routine" "daily" {
  company_id        = paperclip_company.acme.id
  title             = "Daily status {{date}}"
  description       = "Prepare the daily report"
  assignee_agent_id = paperclip_agent.engineer.id
  status            = "active"
  env = { REPORT_FORMAT = { type = "plain", value = "markdown" } }
}
```
