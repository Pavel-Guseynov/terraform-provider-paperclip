# paperclip_agent_key (Ephemeral Resource)

Produces a Paperclip agent key token only during apply for ephemeral or write-only delivery.

## Example Usage

```terraform
ephemeral "paperclip_agent_key" "agent_token" {
  agent_id   = paperclip_agent.engineer.id
  name       = "engineer-key"
  generation = 1
  scope = {
    kind = "standard"
  }
  applying = tofu.applying
}
```
